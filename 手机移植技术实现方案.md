## 1. 项目概述

### 1.1 项目背景

ZeroClaw 是一个用 100% Rust 编写的 AI 助手基础设施项目，具有极低的资源占用和快速的启动时间。为了扩展 ZeroClaw 的应用场景，需要将其移植到移动平台（iOS 和 Android），使用户能够在移动设备上使用 ZeroClaw 的 AI 助手功能。

### 1.2 项目目标

- **核心目标**: 在 iOS 和 Android 平台上提供完整的 ZeroClaw 功能
- **性能目标**: 应用启动时间 < 2s，内存占用 < 50MB
- **用户体验**: 提供流畅的移动端 UI，支持离线模式
- **功能完整性**: 支持核心功能（聊天、工具调用、记忆管理、配置管理）

### 1.3 技术选型

| 技术组件 | 选型 | 理由 |
|---------|------|------|
| 移动框架 | Tauri Mobile | 与 ZeroClaw 架构契合，可复用 Web 界面 |
| 后端语言 | Rust | 与 ZeroClaw 核心一致，性能优异 |
| 前端框架 | React 19 | 与现有 Web 界面一致，可复用代码 |
| 构建工具 | Vite | 与现有 Web 构建工具一致 |
| UI 组件库 | Tailwind CSS + Lucide React | 与现有 Web UI 一致 |
| 状态管理 | Zustand | 轻量级，适合移动端 |
| 数据持久化 | SQLite | 与 ZeroClaw 核心一致 |
| 网络请求 | Reqwest | 与 ZeroClaw 核心一致 |

### 4.1 移动端代理 (MobileAgent)

**职责**: 包装 ZeroClaw 核心代理，提供移动端适配

**接口设计**:

```rust
// crates/zeroclaw-mobile/src/agent.rs
use anyhow::Result;
use zeroclaw::agent::Agent;
use zeroclaw::providers::Provider;
use zeroclaw::tools::Tool;
use zeroclaw::memory::Memory;

pub struct MobileAgent {
    agent: Agent,
    config: MobileAgentConfig,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct MobileAgentConfig {
    pub provider_name: String,
    pub model: String,
    pub temperature: f64,
    pub max_tokens: Option<u32>,
    pub enable_memory: bool,
    pub enable_tools: bool,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ChatMessage {
    pub id: String,
    pub role: String,
    pub content: String,
    pub timestamp: i64,
    pub tool_calls: Option<Vec<ToolCall>>,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ToolCall {
    pub id: String,
    pub name: String,
    pub arguments: serde_json::Value,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ChatResponse {
    pub id: String,
    pub message: ChatMessage,
    pub tool_results: Option<Vec<ToolResult>>,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ToolResult {
    pub tool_call_id: String,
    pub result: serde_json::Value,
    pub success: bool,
    pub error: Option<String>,
}

impl MobileAgent {
    pub fn new(config: MobileAgentConfig) -> Result<Self> {
        let provider = zeroclaw::providers::create_provider(
            &config.provider_name,
            None
        )?;
        
        let agent = zeroclaw::agent::AgentBuilder::new()
            .provider(provider)
            .model(&config.model)
            .temperature(config.temperature)
            .max_tokens(config.max_tokens)
            .build()?;
        
        Ok(Self { agent, config })
    }
    
    pub async fn send_message(&self, message: &str) -> Result<ChatResponse> {
        let response = self.agent.process_message(message).await?;
        
        Ok(ChatResponse {
            id: uuid::Uuid::new_v4().to_string(),
            message: ChatMessage {
                id: uuid::Uuid::new_v4().to_string(),
                role: "assistant".to_string(),
                content: response.content,
                timestamp: chrono::Utc::now().timestamp(),
                tool_calls: None,
            },
            tool_results: None,
        })
    }
    
    pub async fn send_message_with_history(
        &self,
        message: &str,
        history: Vec<ChatMessage>
    ) -> Result<ChatResponse> {
        let mut messages = vec![];
        for msg in history {
            messages.push(zeroclaw::providers::ChatMessage {
                role: msg.role.clone(),
                content: msg.content.clone(),
            });
        }
        messages.push(zeroclaw::providers::ChatMessage {
            role: "user".to_string(),
            content: message.to_string(),
        });
        
        let response = self.agent.chat(&messages).await?;
        
        Ok(ChatResponse {
            id: uuid::Uuid::new_v4().to_string(),
            message: ChatMessage {
                id: uuid::Uuid::new_v4().to_string(),
                role: "assistant".to_string(),
                content: response.content,
                timestamp: chrono::Utc::now().timestamp(),
                tool_calls: None,
            },
            tool_results: None,
        })
    }
    
    pub fn get_config(&self) -> MobileAgentConfig {
        self.config.clone()
    }
    
    pub async fn update_config(&mut self, config: MobileAgentConfig) -> Result<()> {
        self.config = config;
        Ok(())
    }
}
```

```rust
use anyhow::Result;
use std::collections::HashMap;

pub struct MobileProviderManager {
    providers: HashMap<String, Box<dyn MobileProvider>>,
    default_provider: String,
}

pub trait MobileProvider: Send + Sync {
    fn name(&self) -> &str;
    async fn chat(&self, messages: Vec<ChatMessage>) -> Result<ChatResponse>;
    async fn stream_chat(&self, messages: Vec<ChatMessage>) -> Result<ChatStream>;
    fn supports_streaming(&self) -> bool;
    fn supports_vision(&self) -> bool;
    fn supports_tools(&self) -> bool;
}

pub struct ChatStream {
    pub receiver: tokio::sync::mpsc::Receiver<StreamChunk>,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct StreamChunk {
    pub content: String,
    pub done: bool,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ProviderConfig {
    pub name: String,
    pub api_key: Option<String>,
    pub base_url: Option<String>,
    pub models: Vec<String>,
    pub default_model: String,
}

impl MobileProviderManager {
    pub fn new() -> Self {
        Self {
            providers: HashMap::new(),
            default_provider: "openai".to_string(),
        }
    }
    
    pub fn register_provider(&mut self, provider: Box<dyn MobileProvider>) {
        let name = provider.name().to_string();
        self.providers.insert(name, provider);
    }
    
    pub fn get_provider(&self, name: &str) -> Option<&dyn MobileProvider> {
        self.providers.get(name).map(|p| p.as_ref())
    }
    
    pub async fn chat(&self, provider_name: &str, messages: Vec<ChatMessage>) -> Result<ChatResponse> {
        let provider = self.get_provider(provider_name)
            .ok_or_else(|| anyhow::anyhow!("Provider not found: {}", provider_name))?;
        provider.chat(messages).await
    }
    
    pub async fn stream_chat(&self, provider_name: &str, messages: Vec<ChatMessage>) -> Result<ChatStream> {
        let provider = self.get_provider(provider_name)
            .ok_or_else(|| anyhow::anyhow!("Provider not found: {}", provider_name))?;
        provider.stream_chat(messages).await
    }
    
    pub fn list_providers(&self) -> Vec<String> {
        self.providers.keys().cloned().collect()
    }
    
    pub fn get_provider_config(&self, name: &str) -> Result<ProviderConfig> {
        let provider = self.get_provider(name)
            .ok_or_else(|| anyhow::anyhow!("Provider not found: {}", name))?;
        
        Ok(ProviderConfig {
            name: name.to_string(),

            base_url: None,
            models: vec![],
```

### 4.3 移动端工具 (MobileTool)

**职责**: 管理移动端可用的工具

**接口设计**:

```rust
// crates/zeroclaw-mobile/src/tools.rs
use anyhow::Result;
use std::collections::HashMap;
use std::sync::Arc;

pub struct MobileToolRegistry {
    tools: HashMap<String, Arc<dyn MobileTool>>,
}

pub trait MobileTool: Send + Sync {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn parameters_schema(&self) -> serde_json::Value;
    async fn execute(&self, args: serde_json::Value) -> Result<ToolResult>;
    fn is_available(&self) -> bool;
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ToolResult {
    pub success: bool,
    pub output: serde_json::Value,
    pub error: Option<String>,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ToolInfo {
    pub name: String,
    pub description: String,
    pub parameters: serde_json::Value,
    pub available: bool,
}

impl MobileToolRegistry {
    pub fn new() -> Self {
        Self {
            tools: HashMap::new(),
        }
    }
    
    pub fn register_tool(&mut self, tool: Arc<dyn MobileTool>) {
        let name = tool.name().to_string();
        self.tools.insert(name, tool);
    }
    
    pub fn get_tool(&self, name: &str) -> Option<Arc<dyn MobileTool>> {
        self.tools.get(name).cloned()
    }
    
    pub async fn execute_tool(&self, name: &str, args: serde_json::Value) -> Result<ToolResult> {
        let tool = self.get_tool(name)
            .ok_or_else(|| anyhow::anyhow!("Tool not found: {}", name))?;
        
        if !tool.is_available() {
            return Err(anyhow::anyhow!("Tool is not available: {}", name));
        }
        
        tool.execute(args).await
    }
    
    pub fn list_tools(&self) -> Vec<ToolInfo> {
        self.tools.values()
            .map(|tool| ToolInfo {
                name: tool.name().to_string(),
                description: tool.description().to_string(),
                parameters: tool.parameters_schema(),
                available: tool.is_available(),
            })
            .collect()
    }
    
    pub fn get_available_tools(&self) -> Vec<String> {
        self.tools.values()
            .filter(|tool| tool.is_available())
            .map(|tool| tool.name().to_string())
            .collect()
    }
}
```

### 4.4 移动端记忆 (MobileMemory)

**职责**: 管理移动端的记忆存储

**接口设计**:

```rust
// crates/zeroclaw-mobile/src/memory.rs
use anyhow::Result;
use chrono::{DateTime, Utc};

pub struct MobileMemory {
    backend: Box<dyn MobileMemoryBackend>,
}

pub trait MobileMemoryBackend: Send + Sync {
    async fn store(&self, entry: MemoryEntry) -> Result<()>;
    async fn recall(&self, query: &str, limit: usize) -> Result<Vec<MemoryEntry>>;
    async fn forget(&self, key: &str) -> Result<()>;
    async fn list(&self, limit: usize) -> Result<Vec<MemoryEntry>>;
    async fn clear(&self) -> Result<()>;
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct MemoryEntry {
    pub key: String,
    pub content: String,
    pub category: String,
    pub timestamp: DateTime<Utc>,
    pub metadata: serde_json::Value,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct MemoryQuery {
    pub query: String,
    pub category: Option<String>,
    pub limit: usize,
}

impl MobileMemory {
    pub fn new(backend: Box<dyn MobileMemoryBackend>) -> Self {
        Self { backend }
    }
    
    pub async fn store(&self, entry: MemoryEntry) -> Result<()> {
        self.backend.store(entry).await
    }
    
    pub async fn recall(&self, query: &str, limit: usize) -> Result<Vec<MemoryEntry>> {
        self.backend.recall(query, limit).await
    }
    
    pub async fn forget(&self, key: &str) -> Result<()> {
        self.backend.forget(key).await
    }
    
    pub async fn list(&self, limit: usize) -> Result<Vec<MemoryEntry>> {
        self.backend.list(limit).await
    }
    
    pub async fn clear(&self) -> Result<()> {
        self.backend.clear().await
    }
}

pub struct SqliteMemoryBackend {
    db: Arc<tokio::sync::Mutex<rusqlite::Connection>>,
}

impl SqliteMemoryBackend {
    pub fn new(db_path: &str) -> Result<Self> {
        let conn = rusqlite::Connection::open(db_path)?;
        
        conn.execute(
            "CREATE TABLE IF NOT EXISTS memory (
                key TEXT PRIMARY KEY,
                content TEXT NOT NULL,
                category TEXT NOT NULL,
                timestamp INTEGER NOT NULL,
                metadata TEXT
            )",
            [],
        )?;
        
        Ok(Self {
            db: Arc::new(tokio::sync::Mutex::new(conn)),
        })
    }
}

#[async_trait::async_trait]
impl MobileMemoryBackend for SqliteMemoryBackend {
    async fn store(&self, entry: MemoryEntry) -> Result<()> {
        let db = self.db.lock().await;
        let metadata_json = serde_json::to_string(&entry.metadata)?;
        
        db.execute(
            "INSERT OR REPLACE INTO memory (key, content, category, timestamp, metadata)
             VALUES (?1, ?2, ?3, ?4, ?5)",
            [
                &entry.key,
                &entry.content,
                &entry.category,
                &entry.timestamp.timestamp().to_string(),
                &metadata_json,
            ],
        )?;
        
        Ok(())
    }
    
    async fn recall(&self, query: &str, limit: usize) -> Result<Vec<MemoryEntry>> {
        let db = self.db.lock().await;
        let pattern = format!("%{}%", query);
        
        let mut stmt = db.prepare(
            "SELECT key, content, category, timestamp, metadata
             FROM memory
             WHERE content LIKE ?1
             ORDER BY timestamp DESC
             LIMIT ?2"
        )?;
        
        let entries = stmt.query_map(
            [&pattern, &(limit as i64)],
            |row| {
                Ok(MemoryEntry {
                    key: row.get(0)?,
                    content: row.get(1)?,
                    category: row.get(2)?,
                    timestamp: DateTime::from_timestamp(row.get(3)?, 0).unwrap(),
                    metadata: serde_json::from_str(row.get::<_, String>(4)?.as_str()).unwrap_or_default(),
                })
            }
        )?
        .collect::<Result<Vec<_>, _>>()?;
        
        Ok(entries)
    }
    
    async fn forget(&self, key: &str) -> Result<()> {
        let db = self.db.lock().await;
        db.execute("DELETE FROM memory WHERE key = ?1", [key])?;
        Ok(())
    }
    
    async fn list(&self, limit: usize) -> Result<Vec<MemoryEntry>> {
        let db = self.db.lock().await;
        
        let mut stmt = db.prepare(
            "SELECT key, content, category, timestamp, metadata
             FROM memory
             ORDER BY timestamp DESC
             LIMIT ?1"
        )?;
        
        let entries = stmt.query_map(
            [&(limit as i64)],
            |row| {
                Ok(MemoryEntry {
                    key: row.get(0)?,
                    content: row.get(1)?,
                    category: row.get(2)?,
                    timestamp: DateTime::from_timestamp(row.get(3)?, 0).unwrap(),
                    metadata: serde_json::from_str(row.get::<_, String>(4)?.as_str()).unwrap_or_default(),
                })
            }
        )?
        .collect::<Result<Vec<_>, _>>()?;
        
        Ok(entries)
    }
    
    async fn clear(&self) -> Result<()> {
        let db = self.db.lock().await;
        db.execute("DELETE FROM memory", [])?;
        Ok(())
```

```rust
use std::collections::HashSet;

pub struct PermissionManager {
    granted_permissions: HashSet<String>,
}

#[derive(Clone, Debug, Serialize, Deserialize)]
pub enum Permission {
    NetworkAccess,
    StorageAccess,
    CameraAccess,
    MicrophoneAccess,
    LocationAccess,
    NotificationAccess,
}

impl PermissionManager {
    pub fn new() -> Self {
        Self {
            granted_permissions: HashSet::new(),
        }
    }
    
    pub fn request_permission(&mut self, permission: Permission) -> Result<bool> {
        let permission_name = format!("{:?}", permission);
        
        #[cfg(target_os = "android")]
        {
            let granted = self.request_android_permission(&permission_name)?;
            if granted {
                self.granted_permissions.insert(permission_name);
            }
            Ok(granted)
        }
        
        #[cfg(target_os = "ios")]
        {
            let granted = self.request_ios_permission(&permission_name)?;
            if granted {
                self.granted_permissions.insert(permission_name);
            }
            Ok(granted)
        }
        
        #[cfg(not(any(target_os = "android", target_os = "ios")))]
        {
            Ok(true)
        }
    }
    
    #[cfg(target_os = "android")]
    fn request_android_permission(&self, permission: &str) -> Result<bool> {
        Ok(true)
    }
    
    #[cfg(target_os = "ios")]
    fn request_ios_permission(&self, permission: &str) -> Result<bool> {
        Ok(true)
    }
    
    pub fn has_permission(&self, permission: Permission) -> bool {
        let permission_name = format!("{:?}", permission);
        self.granted_permissions.contains(&permission_name)
    }
    
    pub fn revoke_permission(&mut self, permission: Permission) {
        let permission_name = format!("{:?}", permission);
```

```rust
    aead::{Aead, KeyInit},
    ChaCha20Poly1305, Nonce,
};
use rand::RngCore;

pub struct DataEncryptor {
    cipher: ChaCha20Poly1305<chacha20poly1305::Key>,
}

impl DataEncryptor {
    pub fn new(key: &[u8; 32]) -> Self {
        let cipher_key = chacha20poly1305::Key::from_slice(key);
        Self {
            cipher: ChaCha20Poly1305::new(cipher_key),
        }
    }
    
    pub fn encrypt(&self, plaintext: &[u8]) -> Result<Vec<u8>> {
        let mut nonce_bytes = [0u8; 12];
        rand::thread_rng().fill_bytes(&mut nonce_bytes);
        let nonce = Nonce::from_slice(&nonce_bytes);
        
        let ciphertext = self.cipher
            .encrypt(nonce, plaintext)
            .map_err(|e| anyhow::anyhow!("Encryption failed: {}", e))?;
        
        let mut result = nonce_bytes.to_vec();
        result.extend(ciphertext);
        Ok(result)
    }
    
    pub fn decrypt(&self, data: &[u8]) -> Result<Vec<u8>> {
        if data.len() < 12 {
            return Err(anyhow::anyhow!("Invalid ciphertext length"));
        }
        
        let (nonce_bytes, ciphertext) = data.split_at(12);
        let nonce = Nonce::from_slice(nonce_bytes);
        
        let plaintext = self.cipher
            .decrypt(nonce, ciphertext)
            .map_err(|e| anyhow::anyhow!("Decryption failed: {}", e))?;
        
        Ok(plaintext)
    }
    
    pub fn generate_key() -> [u8; 32] {
        let mut key = [0u8; 32];
        rand::thread_rng().fill_bytes(&mut key);
        key
    }
}
```

```rust
pub struct MessageCache {
    cache: HashMap<String, CachedMessage>,
    ttl: Duration,
}

#[derive(Clone)]
struct CachedMessage {
    message: String,
    timestamp: Instant,
}

impl MessageCache {
    pub fn new(ttl: Duration) -> Self {
        Self {
            cache: HashMap::new(),
            ttl,
        }
    }
    
    pub fn get(&self, key: &str) -> Option<String> {
        if let Some(cached) = self.cache.get(key) {
            if cached.timestamp.elapsed() < self.ttl {
                return Some(cached.message.clone());
            }
        }
        None
    }
    
    pub fn put(&mut self, key: String, message: String) {
        self.cache.insert(
            key,
            CachedMessage {
                message,
                timestamp: Instant::now(),
            },
        );
    }
    
    pub fn cleanup(&mut self) {
        let now = Instant::now();
        self.cache
            .retain(|_, cached| now.duration_since(cached.timestamp) < self.ttl);
    }
}
```

```rust
    pub fn new(max_size: usize) -> Self {
        Self {
            connections: Vec::with_capacity(max_size),
            semaphore: Arc::new(Semaphore::new(max_size)),
        }
    }
    
    pub async fn acquire(&self) -> Result<Arc<T>> {
        let _permit = self.semaphore.acquire().await?;
        
        if let Some(conn) = self.connections.first() {
            Ok(conn.clone())
        } else {
            Err(anyhow::anyhow!("No available connections"))
        }
    }
    
    pub fn release(&mut self, conn: Arc<T>) {
        self.connections.push(conn);
    }
}
```

```rust
// crates/zeroclaw-mobile/src/metrics.rs
use std::time::Instant;

pub struct MetricsCollector {
    message_count: u64,
    total_response_time: u128,
    error_count: u64,
}

impl MetricsCollector {
    pub fn new() -> Self {
        Self {
            message_count: 0,
            total_response_time: 0,
            error_count: 0,
        }
    }
    
    pub fn record_message(&mut self, response_time: u128) {
        self.message_count += 1;
        self.total_response_time += response_time;
    }
    
    pub fn record_error(&mut self) {
        self.error_count += 1;
    }
    
    pub fn get_average_response_time(&self) -> f64 {
        if self.message_count == 0 {
            return 0.0;
        }
        self.total_response_time as f64 / self.message_count as f64
    }
    
    pub fn get_error_rate(&self) -> f64 {
        if self.message_count == 0 {
            return 0.0;
        }
        self.error_count as f64 / self.message_count as f64
    }
}

pub struct PerformanceTimer {
    start: Instant,
}

impl PerformanceTimer {
    pub fn new() -> Self {
        Self {
            start: Instant::now(),
        }
    }
    
    pub fn elapsed(&self) -> u128 {
        self.start.elapsed().as_millis()
    }
}
```
